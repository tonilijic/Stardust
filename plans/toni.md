# Toni's Rules

General rules about harnessing and design.

- don't use colored gradients/glow effect for shadow
- don't extra bold titles/headings
- max number of font size 3
- one or two font types

- if action color/primary color don't offer too much contrast on light background, for links use text-primary color with text-decoration underline
