A truly full-stack TypeScript framework that just works.

React, Node.js, and Prisma — wired together with auth, jobs, and deployment built in. Ship in a day and own every line. Designed for humans, works beautifully with AI.

>_ Get started See documentation 
import { app, page, query, route } from "@wasp.sh/spec";
import { MainPage } from "./src/MainPage" with { type: "ref" };
import { getTasks } from "./src/tasks" with { type: "ref" };

export default app({
  wasp: { version: "^0.24.0" },
  title: "ToDo App",
  auth: {  // Full-stack auth out-of-the-box.
    userEntity: "User",
    methods: { google: {}, gitHub: {}, email: {} },
    onAuthFailedRedirectTo: "/login"
  },
  spec: [
    route("RootRoute", "/", page(MainPage, {
      authRequired: true
    })),
    query(getTasks, {
      entities: ["Task"]  // Automatic cache invalidation.
    })
  ]
});

The Way of the Wasp

"Onion" architecture

We aim to make every surface of Wasp a layer of APIs: highest level covers 80% of the use cases, and then you can peel layer after layer as you need more, trading simplicity for flexibility.

Truly full-stack

In Wasp, full-stack is not an after-thought, it is the initial and central point of our design since inception of Wasp as an idea.

A powerful, unique specification layer

Wasp stands for Web App SPecification: you describe the full-stack behaviour of your app in *.wasp.ts files, then implement the details in React, Node, Prisma.

Greatest > latest

We are not chasing the bleeding edge. We critically track and curate the latest web dev trends to provide a deeply integrated, cohesive experience.

Managed experience over DIY

You don't build your framework up, you build it down: start with everything working, then take more control where you need it.

Frequently Asked Questions

How is Wasp different from Next.js / Nuxt.js / Gatsby?

Those are frontend-focused frameworks; Wasp's specification layer covers the whole stack — auth, jobs, email, deployment — out of the box.

How is Wasp different from Ruby on Rails or Django?

Wasp brings the batteries-included philosophy of Rails/Django to the TypeScript/React/Node ecosystem, generating ordinary code you own.

How hard is it to learn Wasp?

If you already know React, Node, and Prisma, the *.wasp.ts spec layer is a thin, high-level addition on top.

Do you support only React & Node.js currently?

Yes, currently — React on the frontend and Node.js on the backend, with Prisma for data.
