Get Started

A truly full-stack TypeScript framework that just works.

React, Node.js, and Prisma — wired together with auth, jobs, and deployment built in. Ship in a day and own every line. Designed for humans, works beautifully with AI.

Get Started See Documentation 
import { app, page, query, route } from "@wasp.sh/spec";
export default app({
  wasp: { version: "^0.24.0" },
  auth: {  // Full-stack auth out-of-the-box.
    userEntity: "User",
    methods: { google: {}, gitHub: {}, email: {} }
  },
  spec: [
    route("RootRoute", "/", page(MainPage)),
    query(getTasks, { entities: ["Task"] })
  ]
});

§ AI

Perfect for AI, by design

By making Wasp as easy as possible for humans we made it the ideal framework for AI too.

$ ask "why AI loves Wasp"

  • Clear best practices and structure keep AI's focus on what is important.
  • Less boilerplate, less code, less space for bugs and security issues.
  • No "connection" points where things break — Wasp glues everything together.

§ FAQ

Frequently Asked Questions

How is Wasp different from Next.js / Nuxt.js / Gatsby?

Those are frontend-focused; Wasp's spec layer covers the whole stack.

How is Wasp different from Rails or Django?

Wasp brings batteries-included philosophy to TypeScript/React/Node.

How hard is it to learn Wasp?

If you know React, Node, Prisma — the spec layer is a thin addition.

Do you support only React & Node.js currently?

Yes, currently — with Prisma for data.
